# DataAnalystAgent · Echo

> **Data Analyst** — the feedback loop that attributes outcomes to decisions, routes advice to each agent, and compounds learnings into a playbook.

**Persona: Echo** — the echo that turns results into feedback across the chain.

[简体中文](README_cn.md)

---

## What it does

Attributes outcomes to each stage's decisions and produces: ① routed advice per agent; ② a cumulative playbook queryable by all agents.

## Pipeline position

① Scout research → ② Wright production → ③ Buzz traffic → ④ Vendy sales → ⑤ **Echo** retrospective (advice flows back to all earlier stages)

## Built-in skills

- `anysearch` · `find-skill` — general search and skill discovery

## Constraints

Attribution depends on the traceable labels in each stage's artifact contract (`product_id` / `trend_id` / `channel` / `campaign_id`); be lenient with the early stages (sourcing) and trust the later ones (sales).
